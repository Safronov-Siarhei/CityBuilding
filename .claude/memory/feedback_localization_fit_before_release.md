Before the game's release version, check the localization texts in every language and that none spills out of the box it is given (the user, 2026-11-10).
**Why:** the user saw texts outgrow their plaques/fields (banner lines, plaques) in Russian already; other languages are longer.
**How to apply:** put it on the pre-release checklist; when building UI now, prefer best-fit/limited boxes.
