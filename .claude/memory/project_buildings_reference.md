The user asked (2026-11-12) for a file listing every ACTIVE building with its icon for each level and a
short note on what it does, kept up to date by the project itself.

Built: `Design/Buildings.html` (icons embedded; the app viewer does not show md images) + `.md`, generated by `Tools/docs/buildings_reference.py` (run by `Tools/research/run.ps1`
after every `setup`, or by hand). Sources: buildings.csv (roster, per-level numbers), sandbox.csv (prices and
build time per level), economy.csv (food a day, bakery/smokehouse bonus), `BuildingIds.Hidden` (left out),
`UI/Icons/<Id>[_L<N>].png`, and the one hand-written part `Design/buildings/descriptions.tsv`
(id, note, optional level count).

**Why:** the user wants an always-current overview of the roster, not a snapshot.
**How to apply:** a new/changed/hidden building → fix its line in descriptions.tsv, and commit the
regenerated Buildings.md with the task. Known gap it flags: Shipyard, Lighthouse, TaxHouse have no level
2-5 icons. See [[project-game-design-backlog]] for the roster history.
