Decided with the user 2026-10-28 (discussion, nothing implemented):

- **Sandbox only**, 400×400 mostly sea, **RANDOM generation by seed**. Seed is a short code (e.g. `KX7-42QF`) shown in pause menu, copyable, enterable at new game; the code carries the generator version so an old code says "old version" instead of silently making another map.
- **12-20 islands**, each with a unique noise-made coastline (relief kinds: flat, hilly, rocky, elongated, atoll; few large, 4-6 medium, rest small).
- **Mandatory islands:** player start (yellow zone for the Ратуша), orc main base (far from player; base variants later), bot settlement (trade/war later). All others have no special status: wild animals, monsters, small orc camps, dungeons, resources.
- **No island per ore:** generator puts slots (slope/forest edge/lowland/special) with weighted random contents; a post-check guarantees each resource exists somewhere: wood, stone, iron, coal, copper, gold, animals (wood+stone always near the start).
- **Map edge = «Бурное море»**: dark stormy band ~20-30 m, ships stop at it, storm-scroll frame on the parchment.
- **Fog, 3 states:** never seen = blank parchment with sea serpents and other drawings; seen before = ink sketch (shader already builds the chart from relief — `FogOfWarManager.BuildChart` — add an "explored" mask); seeing now = live world. **Water explored once stays open forever; land falls back to sketch** unless own buildings hold it. Everyone moving on water (orc ships included) is always visible.
- **Lighthouse:** coastal; pay to reveal a chosen zone in its range for a while (e.g. enemy base before attack), with cooldown; payment resource not decided.
- **New: fishing hut** (more fish near the shore = higher output) and **fertile land** (bonus to food production).
