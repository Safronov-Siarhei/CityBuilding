On 2026-10-20 the user called the menu art "максимально дёшево" and asked for a "дорогой интерфейс". I read that as luxury materials (gold medallions, gold corners, a crimson ribbon) and built a gold kit. The user was angry: "я не подразумевал что там должно быть золото, а то что должно быть больше каких-то деталей".

**Why:** for this user "cheap" means sparse or empty: too few details, flat and simple drawings. It is not about the material or the palette. Restyling on a guess cost a whole round.

**How to apply:**
- On "дёшево" / "дорого" feedback, keep the existing skin (parchment/wood, see [[project-ui-skin]]) and add detail: more content, texture, ornament and illustration.
- If it is unclear which screen or element the user means, ask that one question before rebuilding.
- See also [[project-placement-looks]]: there "cheap" also meant flat tint and plain cells.
