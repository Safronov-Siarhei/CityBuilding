The user's idea, 2026-11-15, «запиши идею режима на будущее» -- NOT to be built until asked.

- A mode where the player creates their OWN models for the buildings, reshaping them to their own taste.
- The FIRST model is free; after that each model variant costs a SPECIAL currency (its own, not crystals),
  bought in the main-menu shop ([[project-monetization-ideas]]) -- one variant = one payment.
- The player can always switch a building back to our base models.

**Why:** a personal-taste sink for paid currency, on top of the main-menu «Магазин».
**How to apply:** before designing, ask the open questions: what the editor is (kit of parts / colours /
roof-wall-decor pieces vs free modelling -- mobile-first, see [[feedback-mobile-first-optimization]]); per
building or per building + level; does the look apply in all modes or only the sandbox; can others see it
(PvP snapshots, [[project-pvp-ideas]]); the currency's name, prices, whether it can be earned; moderation
if models are ever shared. Registered in Design/features/ideas.md.
